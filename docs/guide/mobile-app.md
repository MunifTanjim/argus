# Mobile App

The **mobile app** for iOS and Android (in [`app/`](https://github.com/MunifTanjim/argus/tree/main/app))
mirrors the TUI: sessions, status, transcripts, live screen, prompts, and history.
It also adds **Push Notification**. The app notifies you as soon as a session needs
you (a prompt, a question, a finished turn), **even when it is in the background or
killed**.

## Install

### Android

The app is in **Closed Testing** on Google Play. Anyone can join:

1. Join the **[argus-android-app-beta](https://groups.google.com/g/argus-android-app-beta)**
   Google Group with the Google account you use on the device.
2. Open the **[testing opt-in link](https://play.google.com/apps/testing/dev.muniftanjim.argus)**
   and tap **Become a tester**.
3. Follow the link to install **Argus** from the Play Store.

Updates arrive automatically through the Play Store.

### iOS

The app is in **beta** on TestFlight. Anyone can join:

1. Install **[TestFlight](https://apps.apple.com/us/app/testflight/id899247664)**
   from the App Store if you do not have it.
2. Open the **[TestFlight beta link](https://testflight.apple.com/join/nVUbHecZ)**
   on the device and tap **Accept**.
3. Tap **Install** in TestFlight.

## Pairing

The app talks to a **[gateway](/guide/multi-machine)** over the network, so you
need a running gateway. Even on a single machine, start the node in gateway mode
(`argus start --token <TOKEN>`) instead of as a plain local node. A local node
listens only on a unix socket, which the device cannot reach. Then expose the
gateway (a [tunnel](/guide/gateway-tunnel) is the easiest way) and pair the device.

Pairing creates a **per-device token**. Each device connects with its own
revocable credential instead of the master token. Run `argus pair` against the
gateway:

```sh
argus pair --gateway wss://gateway.argus --token <TOKEN>
```

Argus asks the gateway for a new token, prints a **QR code**, and waits for the
device to connect.

Scan the QR in the app. The gateway stores the token (which makes it revocable)
only after a device connects.

Revoke a device with `argus unpair`:

```sh
argus unpair --gateway wss://gateway.argus --token <TOKEN>
```

### Connect over SSH

Instead of exposing the gateway publicly, the app can connect over SSH to a
loopback-bound gateway, the same setup the [CLI uses over
SSH](/guide/multi-machine#ssh-access). In the app's **manual entry** screen,
switch to **SSH** and provide the host, the user (optional, defaults to `root`),
the gateway's loopback port (default `8443`), your token, and an OpenSSH private
key (imported or generated by the app). The device keystore stores the key. The
app pins the host's key on first connect (trust-on-first-use) and rejects a later
change.

## Push Notification

The app notifies you as soon as a session needs you, **even when it is in the
background or killed**. Push is always on and needs no configuration.

**iOS:** push runs over APNs through [PushPort](/guide/pushport). It is on by
default in the published app. Source builds must embed a PushPort app id.

**Android:** push runs over **UnifiedPush**, so it works on any Android device:

- **Google Play devices:** works without setup.
- **De-Googled devices:** install any UnifiedPush distributor (for example
  [ntfy](https://ntfy.sh)), then select it in **Settings → Push notifications**.
- **PushPort:** an alternative to UnifiedPush. See the [PushPort guide](/guide/pushport).

## Voice Input

To dictate prompts, pick a provider in **Settings → Voice Input**:

- **System** uses the device's speech recognizer. Recognition runs on the
  device when it can. Otherwise Apple or the Android speech service processes
  the audio.
- **OpenRouter** uses your own [OpenRouter](https://openrouter.ai) key. Save the
  key and pick a model. Audio goes straight from the device to OpenRouter,
  never through the gateway, and is billed to your account.
